# Lumen Labyrinth

A tiny, self-contained keyboard maze game. One HTML file, no dependencies, no build step.

## Play

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 4173
# then visit http://localhost:4173/opencode-v2-smoke-test/
```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys / `W` `A` `S` `D` | Move |
| `R` | Restart the current chamber |
| `Enter` / `Space` | Continue after clearing a chamber |

Collect every golden shard to unlock the teal gate, then step into it. There are three chambers, each larger than the last.
