## Nightshift — Metro Cab Co.

A lightweight, self-contained 3D taxi-driving game. Serve five fares across a generated city, collect passengers, and get them to their destinations while avoiding buildings and traffic.

### Play

Serve this folder with a static web server (for example, run `python3 -m http.server 3000` here and open `http://localhost:3000`). The game loads Three.js as an ES module from jsDelivr, so an internet connection is needed.

- **W / ↑** accelerate · **S / ↓** reverse / brake
- **A / ←** and **D / →** steer · **Space** handbrake
- **E** pick up or drop off when near a fare · **P / Esc** pause
- Touch controls are available on small screens.
