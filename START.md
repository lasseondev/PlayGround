# 🎮 Warcraft 3D RTS Game - Quick Start Guide

A complete 3D Real-Time Strategy game in the style of Warcraft with three unique races. Get ready for epic battles and territorial conquest!

## 🚀 Quick Start

### 1. Launch the Game
```bash
# Open the game in your browser
open src/simple-game.html

# Or use the main interface
open src/index.html
```

### 2. Choose Your Race
1. **Human Empire** - Balanced warriors with Knights, Archers, and Wizards
2. **Night Elf Alliance** - Magic masters with Rangers, Druids, and Phoenixes
3. **Orc Horde** - Aggressive forces with Grunts, Shamans, and Warlocks

### 3. Start Playing
- Build your base
- Train your units
- Gather resources
- Expand your territory
- Defeat your enemies!

## 🎯 Game Features

### Core Gameplay
- **Three Distinct Factions**: Each with unique units and playstyles
- **Resource Management**: Gather Wood, Gold, and Magic
- **Base Building**: Construct structures and train units
- **Strategic Combat**: Tactical positioning and cover system
- **Campaign Mode**: Progressive difficulty with story missions

### Technical Highlights
- **Engine**: Three.js WebGL
- **Graphics**: 3D models with dynamic lighting and particle effects
- **Audio**: Spatial sound effects and music
- **Controls**: Full keyboard + mouse support
- **Performance**: 60 FPS target with optimized rendering

## 🏛️ Three Civilizations

### Human Empire ⚔️
- **Units**: Knights (melee), Archers (ranged), Wizards (magic)
- **Playstyle**: Balanced and strategic
- **Resource Focus**: Gold-heavy economy

### Night Elf Alliance 🌿
- **Units**: Rangers (ranged), Druids (support), Phoenixes (flying)
- **Playstyle**: Magic and nature-based
- **Resource Focus**: Magic-heavy economy

### Orc Horde 👹
- **Units**: Grunts (melee), Shamans (magic), Warlocks (dark magic)
- **Playstyle**: Aggressive and overwhelming
- **Resource Focus**: Wood-heavy economy

## 🛠️ How to Play

### Basic Controls
- **WASD**: Camera movement
- **Mouse**: Unit selection and commands
- **R**: Build structure
- **F**: Attack/Purchase unit
- **G**: Gather resources
- **T**: Train unit
- **ESC**: Pause menu
- **Tab**: Select units

### Game Objectives
1. **Expand**: Capture new territory and build bases
2. **Economy**: Gather resources and manage production
3. **Defense**: Protect your structures and units
4. **Offense**: Attack enemies and capture their resources
5. **Victory**: Destroy enemy structures or outlast opponents

## 🛠️ Installation

### System Requirements
- **Browser**: Chrome, Firefox, Safari, Edge
- **OS**: Windows, macOS, Linux
- **RAM**: 4GB minimum
- **WebGL**: Required for graphics

### Installation Steps
1. **Clone this repository**
   ```bash
   git clone https://github.com/yourusername/Warcraft-3D-RTS.git
   cd Warcraft-3D-RTS
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Launch the game**
   ```bash
   open src/simple-game.html
   ```
