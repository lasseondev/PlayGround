🏛️ Game Features

🎯 Three Unique Races

Human Empire (balanced warriors), Night Elf Alliance (magic & nature), Orc Horde (aggressive & powerful)

🏗️ Base Building

Construct barracks, towers, and special structures to produce units and gather resources.

⚡ Real-Time Combat

Strategic battles with unit positioning, cover system, and morale-based tactics.

💰 Resource Management

Gather and manage Wood, Gold, and Magic resources to fund your civilization's expansion.

🗺️ Strategic Maps

45-degree angled tactical views and bird's-eye map navigation for optimal positioning.

🎮 Complete Control System

Intuitive unit selection, queue commands, group actions, and formation control.

🛠️ Technical Specifications

Engine: Three.js WebGL
Rendering: Dynamic lighting, shadows, particle effects
Audio: Web Audio API, spatial sound
Controls: Full keyboard + mouse support
Compatibility: Modern web browsers
Performance: 60 FPS target, optimized rendering
